# Hostless blog discussions

Comments and replies for [the Hostless blog](https://blog.hostless.cloud), powered by Giscus. Blog source code stays in the private Hostless monorepo.

Each article maps to `hostless-blog:<post-id>` in the Announcements category. New article threads are created by Giscus when the first comment is posted.

## Community guidelines

Be constructive and stay on topic. Do not post passwords, tokens, account identifiers, or private customer information. Comments and replies are public. Maintainers may edit, hide, lock, or remove spam, abuse, or sensitive information through GitHub Discussions.

Use [Hostless support](mailto:support@hostless.cloud) for private account issues.
